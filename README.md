# Port Traffic Monitoring System

## Project Overview
The Port Traffic Monitoring System is a web-based application developed as a Final Year Project to support port management and monitor network activity. It provides an administrative dashboard for managing port information, users, and traffic logs.

## Objectives
- Provide a centralized interface for managing port-related information.
- Record and display network monitoring logs.
- Support network scanning using Nmap.
- Present monitoring information through an administrative dashboard.

## Features
- Admin login and authentication
- Add, edit, and delete port records
- User management
- Network scanning using Nmap
- Traffic log management
- Monitoring dashboard

## Technologies Used
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Network Scanning:** Nmap
- **Local Development Environment:** XAMPP

## Installation and Setup
1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Create the project database in phpMyAdmin.
6. Import the project's SQL file, if included in the repository.
7. Update the database connection settings in the project configuration file.
8. Open the project in your browser using `http://localhost/your-project-folder`.

## Project Purpose
This project demonstrates practical skills in web application development, database management, and network scanning integration.
